# Bibliographie du cours

La liste des sources sur lesquelles le cours s'appuie. **Ce fichier est
versionné** — contrairement aux documents eux-mêmes, qui restent locaux.

Complétez-le au fur et à mesure, pas à la fin : une source qu'on retrouve en
relisant est une source qu'on cite mal.

## Comment remplir

Une entrée par source, avec assez d'informations pour que quelqu'un d'autre la
retrouve. La colonne **Statut** dit ce que la source pèse dans le cours :

- **Fondement** — le cours en découle directement ; on ne s'en écarte pas.
- **Appui** — sert à illustrer, préciser, nuancer.
- **Contexte** — lu pour se situer, pas cité dans le cours.

## Lacunes connues

Ce que les sources **ne couvrent pas**, et qu'il faudra donc traiter autrement —
par un entretien, une recherche complémentaire, ou en assumant que le cours
n'aborde pas le point.

- *(à compléter pendant le cadrage)*

## Points de désaccord entre sources

Quand deux sources se contredisent, on le note ici et on dit laquelle le cours
suit, avec la raison. Un cours qui tranche sans le dire laisse l'apprenant
désarmé le jour où il rencontre l'autre version.

- *(à compléter pendant le cadrage)*
