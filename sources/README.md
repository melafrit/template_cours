# Documents de référence

Déposez ici **tout ce sur quoi le cours doit s'appuyer** : référentiel de
certification, supports existants, articles, normes, textes officiels, notes de
cadrage, comptes rendus. Claude les lit **avant** de poser la moindre question
de cadrage, et s'en sert comme source de vérité pour rédiger.

## Ce dossier n'est pas versionné

Le `.gitignore` exclut tout son contenu, à deux exceptions près : ce fichier et
`bibliographie.md`.

La raison n'est pas la place : c'est le **droit d'auteur**. Un référentiel de
certification, un manuel, un article de revue ne vous appartiennent pas, et
l'historique Git ne s'efface pas. Ce qu'on y met un jour y reste — y compris le
jour où le dépôt devient public.

La bibliographie, elle, est versionnée : citer une source n'est pas la
republier, et c'est la trace vérifiable de ce sur quoi le cours repose.

## Comment organiser

Rien n'est imposé, mais une organisation qui fonctionne :

```
sources/
  01-referentiel/     le cadre officiel : compétences, blocs, attendus
  02-fond/            manuels, articles, normes, textes de référence
  03-existant/        vos supports actuels, s'il y en a
  04-notes/           vos notes, comptes rendus de réunion, contraintes
  bibliographie.md    la trace publiable — à compléter au fur et à mesure
```

## Ce que Claude en fait

- **Il lit avant de demander.** Les questions de cadrage viennent après la
  lecture, pas avant : elles portent alors sur ce qui manque réellement.
- **Il cite.** Chaque affirmation du cours qui vient d'une source la mentionne —
  titre, section, page.
- **Il signale les trous.** Une information absente des documents est annoncée
  comme absente. Elle n'est pas comblée par une invention plausible, qui est ce
  qu'un cours peut avoir de pire : faux, et crédible.
- **Il signale les contradictions** entre deux sources plutôt que d'en choisir
  une en silence.

## Formats

PDF, DOCX, PPTX, Markdown, texte, HTML. Les scans d'images sans couche texte ne
sont pas exploitables : faites-les passer par une reconnaissance de caractères
avant de les déposer, sinon Claude ne voit qu'une image.
