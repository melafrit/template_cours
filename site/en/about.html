    About

    This site isn't just a course: it's the demo of a reusable template for online course sites, designed to be reused, translated and adapted to any topic.

    A template, not just a course

    The visible content ("Designing an online course") acts as a through-line: it teaches instructional design while demonstrating, page after page, what the template can do. You can empty this content and replace it with your own: the structure, navigation and components stay in place. It is a static site (vanilla HTML, CSS and JavaScript, no dependency or build step), easy to host anywhere.

    What the template offers

    🌍Bilingual FR/EN

    Twin content via data-tr and a 🌐 language switch active across the whole site.

    🧭Auto navigation

    Contents, side menu and section tree generated from a single source.

    🎨Light / dark theme

    A 🌙 toggle and a restrained institutional design built on CSS variables.

    ♿Accessibility

    Dedicated panel: text size, reading-friendly font, reduced motion.

    📝Graded quiz

    Certainty-based marking (CBM), correction and dashboard.

    🧩Learning components

    Callouts, concept grids, "key takeaways" boxes, flashcards, interactive glossary.

    Author
